Set up the robot

  1. 1. Mark the board

    Click the board's four outer corners in this order: a1, h1, h8, a8. a1 is the square to the left of the white pieces.

  2. 2. Choose where it waits optional

    Jog the arm with the Robot controls to somewhere clear of the board, then save that as the park pose.

  3. 3. Save

    Stores the calibration so perception and the arm agree on where the board is. Marking the board is enough; anything you skip keeps what was stored before.

  4. Refine the camera optional

    The board is measured against where the description says the camera is. If that is not where it actually hangs, touching the same four corners you clicked above with the gripper - by hand, since the arm releases its motors so you can guide it - gives the real 3D positions to fit the camera's pose against. Mark the board first: these are the same points.
