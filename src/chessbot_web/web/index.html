Set up the robot

  1. 1. Measure the board

    The arm measures the board itself. Release it, then guide it by hand so the closed jaw tips rest on each outer corner in turn - a1, h1, h8, a8, where a1 is the square to the left of the white pieces - and confirm each one. This gives where the board is, how big its squares are and how high it sits, all from the arm's own kinematics.

      tool —

    1. 2. Place the camera

      Click the same four corners in the photo, in the same order. Paired with where the arm touched them, this is where the camera is - which is how perception knows which pixels are which square. The arm does not depend on it.

    2. 3. Choose where it waits optional

      Jog the arm with the Robot controls to somewhere clear of the board, then save that as the park pose.

    3. 4. Save

      Stores the calibration so perception and the arm agree on where the board is. Anything you skip keeps what was stored before.
