Set up the robot

  1. 1. Find the camera

    The arm moves through a few poses and opens its jaws so the camera can see where the gripper is. Keep the workspace clear.

  2. 2. Mark the board

    Click the board's four outer corners in this order: a1, h1, h8, a8. a1 is the square to the left of the white pieces.

  3. 3. Choose where it waits

    Jog the arm with the Robot controls to somewhere clear of the board, then save that as the park pose.

  4. 4. Save

    Stores the calibration so perception and the arm agree on where the board is.
